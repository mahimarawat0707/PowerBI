# Hospital Analytics Dashboard

A comprehensive Hospital Analytics Dashboard built using Metabase to monitor patient activity, appointments, revenue, departmental performance, anesthesia procedures, and patient satisfaction metrics.

## Project Overview

This dashboard provides healthcare administrators and management teams with actionable insights through interactive visualizations and key performance indicators (KPIs). It enables efficient monitoring of hospital operations and supports data-driven decision-making.

---

## Features

### Patient Analytics
- Total Patients
- New vs Returning Patients
- Age Group Distribution
- Gender Distribution
- Patient Registration Trends

### Appointment Analytics
- Total Appointments
- Appointment Status Tracking
- Daily & Monthly Appointment Trends
- Average Waiting Time Analysis

### Department Analytics
- Department-wise Patient Count
- Most Visited Departments
- Department Performance Comparison

### Revenue & Billing Analytics
- Total Revenue
- Revenue by Department
- Payment Method Distribution
- Billing Trends

### Anesthesia Analytics
- Total Procedures
- Procedure Type Distribution
- Department-wise Analysis

### Patient Satisfaction
- Average Satisfaction Score
- Feedback Distribution
- Satisfaction Trends
