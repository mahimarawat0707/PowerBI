# Healthcare Analytics Dashboard

## Overview

The **Healthcare Analytics Dashboard** is an interactive Power BI dashboard designed to provide comprehensive insights into hospital operations, patient demographics, medical conditions, billing performance, and healthcare trends.

This dashboard enables healthcare administrators, analysts, and decision-makers to monitor key performance indicators (KPIs), identify patterns in patient data, and support data-driven healthcare management.

---

## Objectives

- Monitor overall patient volume and hospital statistics.
- Analyze patient demographics and blood group distribution.
- Track billing performance and financial metrics.
- Understand admission patterns and medical conditions.
- Support strategic healthcare decision-making through visual analytics.

---

## Dashboard Features

### KPI Cards

The dashboard highlights key healthcare metrics:

| Metric | Description |
|----------|-------------|
| Total Patients | Total number of patients recorded |
| Total Doctors | Total number of doctors available |
| Total Hospitals | Total hospitals included in the dataset |
| Total Billing Amount | Total revenue generated from patient billing |

---

### Patient Demographics

#### Gender Distribution
- Visualized using a donut chart.
- Displays the proportion of:
  - Male Patients
  - Female Patients

#### Blood Type Analysis
- Distribution of patients across blood groups:
  - A+
  - A-
  - B+
  - B-
  - AB+
  - AB-
  - O+
  - O-

---

### Patient Room Analysis

- Displays the number of patients assigned to different room numbers.
- Helps identify room occupancy trends and utilization.

---

### Detailed Patient Records

The dashboard includes a detailed table containing:

- Patient Name
- Age
- Gender
- Blood Type
- Admission Type
- Medical Condition
- Test Results
- Medication
- Billing Amount

This allows users to drill down into individual patient-level information.

---

## Interactive Filters

Users can dynamically filter the dashboard using:

- Year Filter
- Month Filter
- Day Filter

These slicers enable time-based analysis and trend monitoring.
