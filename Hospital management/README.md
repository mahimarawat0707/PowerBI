# 🏥 Hospital Management Dashboard - Power BI Project

## 📌 Project Overview

This project is a **Hospital Management Dashboard** created using **Power BI** to analyze and visualize healthcare-related data such as:

- Patient records
- Doctor information
- Appointments
- Billing & payment status
- Department analytics
- Blood group statistics
- Admission & discharge trends

The dashboard helps hospitals and healthcare administrators monitor operations, patient distribution, financial insights, and departmental performance through interactive visualizations.

---

# ✨ Features

## 📊 Main Dashboard
The main dashboard provides a complete overview of:

- Patient count by blood group
- Treatment cost by payment status
- Average consultation fee by doctor
- Doctor distribution by department

### Visuals Used
- Bar Chart
- Pie Chart
- Donut Chart
- Interactive Filters

---

## 🧑‍⚕️ Patients Dashboard
This page focuses on patient-related analytics:
