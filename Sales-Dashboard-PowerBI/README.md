# 📊 Mahima E-Commerce Dashboard

An interactive Power BI dashboard built to analyze e-commerce sales, stock availability, brands, customer distribution, and product insights.

---

## 🚀 Project Overview

This dashboard helps visualize and monitor:
- Product pricing
- Stock availability
- Brand distribution
- Customer count by brand
- Category-wise availability
- Company stock performance

The goal of this project was to practice:
- Data visualization
- Dashboard design
- Business intelligence concepts
- Power BI reporting
- DAX basics
- Data storytelling


## 🛠 Tools & Technologies Used

- Power BI
- Power Query
- DAX
- Excel / CSV Dataset
- Data Cleaning
- Data Visualization

---

## 📌 Features

- Interactive filters and slicers
- KPI summary cards
- Brand-wise analysis
- Stock distribution charts
- Category-based insights
- Dark-themed dashboard UI
- Responsive visual layout
